Jedna se o TowerDefenseSimulator
Nachází se zde až 4 druhy nepřátel
Pokud nepřítel doběhne do základny, ubere jí tolik HP, kolik mu zbylo životů.

Věže se kupují stisknutím tlačítka E, věž se objeví na aktuální pozici myši
první věž stojí 1000 bodů, poté se po koupi každé věže cena zvýší o 250 bodů

Hru spustíte stiskem mezerníku.
Každou 10 wawe se spawnuje boss, ten má poprvé 50 životů.
Věž dává 1 střelou poškození 1 život.

Ve hře se postupně zvyšují životy nepřátel, a to takto:
wave 1–9:
typ 1 = 1 HP
typ 2 = 2 HP
typ 3 = 3 HP

wave 10–19:
typ 1 = 2 HP
typ 2 = 3 HP
typ 3 = 4 HP
...
